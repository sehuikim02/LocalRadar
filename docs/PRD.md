# [PRD] 로컬레이더 (LocalRadar) 제품 요구사항 정의서

## 1. 프로젝트 개요 (Project Overview)
- **제품명**: 로컬레이더 (LocalRadar)
- **한 줄 슬로건**: "광고는 거르고, 찐후기만 남긴다 — AI 기반 동네 핫플·로컬 맛집 스펙 큐레이션 매거진"
- **제품의 존재 이유**: 
  인터넷 검색 환경에서 '내돈내산'이라는 검색어조차 바이럴 마케팅과 원고료 지원 포스팅으로 오염되어, 소비자가 순수한 방문객 후기를 찾기 위해 수많은 블로그 탭을 열고 닫으며 시간과 노력을 낭비하는 극심한 탐색 피로도를 겪고 있습니다. 로컬레이더는 대가성 광고 글을 AI로 자동 차단하고, 방문객의 실제 경험에서 **주차·웨이팅·장단점** 등 핵심 방문 스펙만을 추출·정형화하여 10초 만에 실패 없는 장소 선택을 돕기 위해 탄생했습니다.
- **문서 버전**: v1.2.0 (MVP Final Complete)
- **작성 및 관리**: 기획/개발팀 (sehuikim)
- **최종 개정일**: 2026-11-19

## 2. 목표 및 비전 (Objectives & Success Metrics)

### 2.1 비전 (Vision)
소비자가 낯선 동네나 새로운 약속 장소를 찾을 때 마케팅 홍보성 글에 속지 않고, 마치 그 동네에 사는 현지인 친구가 솔직하게 알려주듯 투명하고 신뢰도 높은 로컬 정보를 즉시 획득할 수 있는 **대한민국 No.1 신뢰 기반 로컬 큐레이션 플랫폼**으로 자리매김합니다.

### 2.2 핵심 성공 지표 (KPIs)
1. **비즈니스 & 데이터 품질 지표**:
   - **광고성 글 필터링 정확도 (Ad Filtering Accuracy)**: 대가성/원고료/협찬 포스팅 감별률 **90% 이상** 유지.
   - **가게 정보 추출 신뢰도 (Place Spec Accuracy)**: 상호명 오추출(메뉴명, 일반명사 혼동) 비율 **0%** 달성.
   - **지도 검색 성공률 (Map Link Reachability)**: 네이버 지도 연동 시 정상 플레이스 매칭률 **98% 이상**.
2. **사용자 경험(UX) 지표**:
   - **탐색 소요 시간 절감**: 기존 10~15분(블로그 10개 정독) ➔ **15초 이내(원클릭 스캔 및 비교표 확인)**로 단축 (98% 시간 절감).
   - **스캔 전환율**: 랜딩 뷰 방문자의 핫플 TOP 10 원클릭 스캔 및 지역 검색 전환율 **80% 이상**.

## 3. 주요 타겟 사용자 (Target Audience & Personas)

### 3.1 타겟 사용자 그룹
- **주말 데이트 및 약속 장소 탐색자 (2030 세대)**: 인스타그램/블로그 광고에 실패한 경험이 많아 검증된 분위기 맛집·신상 카페를 빠르게 찾고 싶은 사용자.
- **카공족 & 디지털 노마드 (대학생/프리랜서)**: 콘센트 유무, 노트북 작업 분위기, 소음 정도, 주차 가능 여부를 사전에 확실히 체크해야 하는 사용자.
- **출장자 & 로컬 미식 여행자**: 관광객 전용 광고 맛집 대신 현지인이 즐겨 찾는 진짜 노포와 로컬 숨은 맛집을 발굴하고 싶은 사용자.

## 5. UI / UX 설계 명세

### 5.1 에디토리얼 디자인 시스템
- **컬러 팔레트**:
  - Main Background: `Warm Ivory / Off-White (#FAF9F6)` — 눈의 피로도를 낮추는 감각적인 종이 질감.
  - Card Background: `Pure White (#FFFFFF)` with `1px solid #EFECE6`, `box-shadow: 0 4px 20px rgba(0,0,0,0.03)`
  - Primary Accent: `Coral Orange (#FF5A36)` — 큐레이션 전문성과 활력을 상징.
  - Dark Charcoal: `#1E1E1E` — 명도 대비가 뚜렷한 프리미엄 서체.
- **타이포그래피**: Google Web Font 'Pretendard' 전역 적용.

### 5.2 화면 컴포넌트 세부 명세
1. **상단 히어로 배너**: 둥근 모서리(`border-radius: 20px`)의 피치-코랄 그라데이션 카드, 브랜드 뱃지, 실시간 상태 Pill 뱃지(`🟢 Gemini 2.5 Flash`).
2. **사이드바 컨트롤 패널**: 가로폭 400~460px 확장, 화이트 배경, 2rem 간격 컴포넌트 배치, 가로형 라디오, 코랄 그라데이션 풀폭 CTA 버튼.
3. **실시간 프로그레스 UX**: 네온 코랄 그라데이션(`linear-gradient`) 및 단계별 텍스트 알림(0% ➔ 15% ➔ 50% ➔ 70% ➔ 100%).
4. **결과 대시보드 3단 레이아웃**:
   - 3개 독립 KPI 스탯 카드 (걸러낸 광고 카드 강조).
   - `💡 로컬레이더 AI 상권 브리핑` 박스.
   - 베스트 Pick TOP 3 카드 (1위 카드 전용 테두리 및 `BEST PICK` 리본, 네이버 지도 바로가기 버튼).
   - 전체 비교표 및 태그 칩(`st.pills`) 필터링 바.

## 6. 시스템 아키텍처 & Tech Spec

### 6.1 시스템 아키텍처 다이어그램 (Architecture)
```
+---------------------------------------------------------------------------------+
|                                Streamlit Frontend                               |
|   - Hero Magazine Banner & Responsive Sidebar (Warm Editorial Theme)           |
|   - Real-time Coral Progress Bar (0% -> 100%)                                   |
|   - Curation Result Dashboard (KPI Stats, Best Picks TOP 3, DataFrame, st.pills)|
+----------------------------------------+----------------------------------------+
                                         | Trigger Search Event
                                         v
+---------------------------------------------------------------------------------+
|                        Web Crawling Engine (Python Requests)                    |

+----------------------------------------+----------------------------------------+
                                         | Cleaned Review Array (JSON)
                                         v
+---------------------------------------------------------------------------------+
|                      Google Gemini Analysis Engine (v1beta)                     |

|   - Prompting: Combined Full Prompt + Strict JSON Schema Enforcement             |
|   - Logic: Ad/Sponsorship Filtering, Store Deduplication, Pure Name Cleaning    |
+----------------------------------------+----------------------------------------+
                                         | Structured Output (Valid JSON)
                                         v
+---------------------------------------------------------------------------------+
|                        Data Transformation & Post-Processing                    |
|   - build_naver_map_url: Refine place name -> Generate Naver Map Query Link     |

+---------------------------------------------------------------------------------+
```

## 7. MVP 범위 및 핵심 기능 명세 (MVP Scope & Key Features)

### 7.1 MVP 정의 및 개발 전략
본 MVP(Minimum Viable Product)는 **"사용자가 15초 이내에 광고 없는 동네 찐맛집과 신상 카페의 핵심 스펙(주차·웨이팅·장단점)을 비교하고 위치를 확인한다"**라는 핵심 가치 증명에 집중합니다. 복잡한 DB나 회원가입 없이 단일 Streamlit 웹 앱으로 완성도 높은 실사용성을 제공합니다.

### 7.3 제외 범위 (Out of Scope - 이번 MVP 릴리즈에서 제외)
1. **사용자 로그인 및 회원가입 (Authentication)**: 불필요한 가입 절차 없이 누구나 즉시 탐색할 수 있도록 비로그인 웹 앱 형태로 운영.
2. **개인별 스크랩 및 북마크 클라우드 저장소**: DB 서버 의존성을 없애고 로컬 CSV 다운로드로 대체.
3. **네이버/카카오/구글 지도 API 실시간 지도 임베딩 (Map SDK)**: 무거운 지도 컴포넌트 렌더링으로 인한 속도 저하를 방지하고, 직관적인 네이버 지도 새창 다이렉트 링크 버튼으로 대체.
4. **인스타그램, 카카오맵, 유튜브 등 멀티 채널 크롤링**: 1차 버전은 가장 텍스트 리뷰 표본이 풍부한 '네이버 블로그'에 집중.
5. **실시간 길찾기 및 네비게이션 동선 최적화**: 매장 위치 파악 및 스펙 비교에 집중하며 경로 안내는 제외.
