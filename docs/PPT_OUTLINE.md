### [슬라이드 5] 시스템 아키텍처 & 기술 스택
- **제목**: 견고하고 빠른 풀스택 데이터 파이프라인
- **핵심 메시지**: "Python 생태계의 장점을 극대화한 경량·고성능 아키텍처"
- **본문 내용**:
  - **UI / App Framework**: `Streamlit 1.56.0` (반응형 상태 관리, CSS 테마 커스텀).
  - **Data Collection**: `Requests` + `BeautifulSoup4` (User-Agent 위장, 상위 카드 역탐색).
  - **AI Analysis**: `Google GenAI SDK (gemini-2.5-flash)` (Structured JSON Outputs 강제).
  - **Data Processing**: `Pandas` (데이터 가공, 실시간 태그 필터링, UTF-8-SIG CSV 생성).
- **시각 자료 가이드**: PRD에 기술된 ASCII 데이터 흐름도를 깔끔한 블록 다이어그램으로 시각화.

- **제목**: 기술적 난관 극복과 완성도 높은 구현
- **핵심 메시지**: "안정적인 크롤링과 철저한 예외 방어 로직 설계"
- **본문 내용**:

- **시각 자료 가이드**: `build_naver_map_url` 정제 전/후 비교 예시 및 Gemini 모델 폴백 흐름도.
