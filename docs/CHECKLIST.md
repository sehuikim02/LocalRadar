## 1. 환경 설정 및 보안 (Environment & Security)
- [O] **`.env` 파일 분리 및 보호**: 실제 구글 제미나이 API 키(`GEMINI_API_KEY`)가 코드 파일에 하드코딩되지 않고 `.env` 파일에 안전하게 보관됨.
- [O] **`.env.example` 템플릿 제공**: 신규 배포자 및 평가자를 위한 더미 환경 변수 템플릿(`.env.example`)이 프로젝트 루트에 구비됨.
- [O] **UI 상의 API 키 노출 제거**: 화면 및 사이드바에서 비밀키 입력 필드를 완전히 제거하여 화면 공유나 시연 중 보안 누출을 원천 차단함.
- [O] **제출용 압축 파일 배제 검증**: 과제 제출 압축 파일(`.zip`) 생성 시 `.env`, `__pycache__`, 가상환경 폴더가 철저히 제외되도록 필터링 처리함.

## 2. 웹 크롤링 및 데이터 수집 (Web Crawling & Parsing)
- [O] **HTTP 요청 위장 및 헤더 최적화**: 봇 탐지 및 403 차단을 방지하기 위해 정밀한 `User-Agent` 및 `Referer: https://www.naver.com/` 헤더를 적용함.
- [O] **HTML 동적 변경 방어 로직**: 네이버 블로그 검색 결과의 난독화/동적 클래스명에 의존하지 않고 `a[href*='blog.naver.com']` 기반 부모 컨테이너(상위 카드)를 역탐색하여 추출 안정성을 확보함.
- [O] **텍스트 정제 및 노이즈 제거**: '새 창 열림', 'Keep에 저장', 줄바꿈 및 특수문자 엔티티를 정규식으로 완벽히 정제하여 순수 후기 본문만 수집함.
- [O] **예외 처리 및 안전 장치**: 수집 결과가 0건이거나 네트워크 타임아웃 발생 시 크래시 없이 사용자에게 친절한 가이드 안내 메시지를 표시함.

## 3. AI 분석 파이프라인 (Gemini Analysis Engine)
- [O] **Structured Outputs 강제**: Google GenAI SDK의 `response_mime_type="application/json"` 및 JSON 스키마를 통해 지정된 규격으로만 응답을 강제함.
- [O] **v1beta API 엔드포인트 연동**: 구글 v1 버전 미지원 이슈를 사전에 방지하기 위해 `http_options={"api_version": "v1beta"}`로 안정적으로 초기화함.
- [O] **시스템 지시문 단일 통합 프롬프트**: 단일 결합 프롬프트(`full_prompt`) 방식을 채택하여 API 호환성 오류를 원천 차단함.
- [O] **503 트래픽 과부하 방어 (자동 재시도 & 모델 폴백)**: 구글 클라우드 트래픽 급증(503 UNAVAILABLE) 발생 시 지연 재시도 및 `gemini-2.5-flash` ➔ `gemini-2.0-flash` ➔ `gemini-1.5-flash` 순으로 자동 전환되도록 구현함.
- [O] **실존 상호명(place_name) 엄격 정제**: 메뉴명(버터케이크 등)이나 지역명, 일반명사가 가게 이름으로 추출되지 않도록 프롬프트 룰을 강력하게 고도화함.

## 4. UI / UX 및 기능 완성도 (User Experience & Features)
- [O] **여유롭고 모던한 사이드바 레이아웃**: 사이드바 너비를 400~460px로 확장하고 컴포넌트 간 충분한 여백(1.8~2.2rem) 및 가로형 라디오 버튼을 적용함.
- [O] **화사한 네온 코랄-오렌지 프로그레스 바**: 진행률 0%부터 100%까지 단계별 상태 메시지와 함께 생동감 있는 커스텀 그라데이션 프로그레스 바를 렌더링함.
- [O] **전국 핫플 TOP 10 원클릭 스캔**: 2행 5열 카드 그리드 클릭 시 사이드바 입력창 위젯과 실시간 동기화되어 즉각적인 분석이 실행됨.
- [O] **상태 충돌 방지 (`pending_region`)**: 위젯 인스턴스화 이후 세션 상태 직접 변경으로 인한 `StreamlitAPIException` 에러를 원천 차단함.
- [O] **스마트 네이버 지도 URL 생성기 (`build_naver_map_url`)**: 수식어와 군더더기를 걷어내고 '동 단위 + 순수 상호명'으로 조합하여 네이버 지도에서 정확한 위치가 즉시 열리도록 보정함.
- [O] **실시간 태그 필터링 (`st.pills`)**: 추출된 고유 해시태그를 클릭하면 추가 API 호출 없이 테이블 행이 실시간 필터링됨.
- [O] **UTF-8-SIG CSV 익스포트**: 한국어 엑셀 프로그램에서 한글이 깨지지 않도록 BOM이 포함된 CSV 다운로드 기능 제공.
